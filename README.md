# 개인 PLM 대시보드 (로컬 웹 · 모바일 연동)

과제, 프로젝트/마일스톤, 리스크, 아이디어 노트, 로드맵을 한 곳에서 관리하는
개인용 로컬 웹 대시보드입니다. 외부 npm 패키지 없이 Node.js 표준 라이브러리만
사용하므로 인터넷 연결 없이도 실행됩니다(글꼴만 온라인 CDN을 사용하며, 오프라인
에서도 시스템 기본 글꼴로 정상 동작합니다).

## 요구 사항

- Node.js 16 이상 설치 (https://nodejs.org 에서 LTS 버전 다운로드)
- 별도 설치할 패키지 없음 (`npm install` 불필요)

## 실행 방법

```bash
cd plm-dashboard
node server.js
```

실행하면 아래와 같은 로그가 출력됩니다.

```
PLM 대시보드 서버 실행 중
  로컬:   http://localhost:4000
  모바일: http://192.168.0.12:4000  (같은 Wi-Fi 필요)
```

- PC/맥에서는 브라우저로 `http://localhost:4000` 접속
- **모바일 연동**: 휴대폰이 PC와 **같은 Wi-Fi(공유기)**에 연결되어 있어야 합니다.
  로그에 출력된 `모바일: http://192.168.x.x:4000` 주소를 휴대폰 브라우저에
  그대로 입력하면 동일한 데이터를 실시간으로 보고 편집할 수 있습니다.
- 포트를 바꾸고 싶으면 `PORT=5000 node server.js` 처럼 실행하세요.

## 모바일 접속이 안 될 때 체크리스트

1. PC 방화벽에서 Node.js(또는 지정한 포트)의 인바운드 연결을 허용했는지 확인
2. PC와 휴대폰이 정말 같은 네트워크(같은 공유기)에 있는지 확인 — 회사망은
   기기 간 통신을 막아둔 경우가 많습니다(AP 격리). 이 경우 개인 핫스팟이나
   가정용 공유기에서는 정상 동작합니다.
3. 항상 같은 주소로 접속하고 싶다면 공유기 설정에서 PC에 고정 IP를 할당하세요.
4. 완전히 외부(공유기 밖)에서 접속하려면 포트포워딩이나 Tailscale/ZeroTier 같은
   사설 VPN 구성이 추가로 필요합니다 — 이 구성은 보안 설정이 필요해 기본
   제공하지 않았습니다. 필요하시면 별도로 안내해 드릴 수 있습니다.

## 데이터 저장

모든 데이터는 `data/db.json` 파일에 저장됩니다. 별도 데이터베이스 설치가
필요 없고, 이 파일을 백업하거나 다른 PC로 옮기면 데이터가 그대로 이전됩니다.

## 구조

```
plm-dashboard/
├── server.js        # API 서버 (Node 표준 라이브러리만 사용)
├── package.json
├── data/
│   └── db.json       # 데이터 저장 파일
└── public/
    ├── index.html
    ├── style.css
    └── app.js
```

## 기능

- **과제**: 상태(진행중/보류/완료), 진행률, 마감일
- **프로젝트 · 마일스톤**: 프로젝트별로 마일스톤을 추가하고 완료 체크
- **리스크**: 심각도(낮음/중간/높음), 대응 상태 추적
- **아이디어 노트**: 자유 형식 메모 + 태그
- **로드맵**: 시기별(예: 2026 Q4) 계획 항목 정렬

## 확장하고 싶다면

- 외부에서도 접속하고 싶다: Tailscale 설치 후 같은 계정으로 PC·휴대폰 연결
- 데이터가 많아지면: `db.json` 대신 SQLite로 교체 (구조 변경 필요)
- 로그인 기능이 필요하다: 기본 인증(Basic Auth) 미들웨어 추가 가능
